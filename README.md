# 🎂 Mom's Magic — Cake Ordering Website

A responsive cake ordering website built with React that allows users to explore cakes, customize orders, get dynamic price estimates, and place cake requests through WhatsApp.

## 🌐 Live Demo

https://moms-magic-cake-website.vercel.app

## ✨ Features

- 🍰 Browse bestselling cakes with prices and ratings
- 🎂 Interactive custom cake builder
- 💰 Dynamic price calculation based on flavour and cake size
- 🎉 Occasion and personalized cake-message selection
- 📱 WhatsApp-based cake ordering
- 🧩 Reusable React components
- 📱 Responsive design for desktop and mobile
- ⚡ Fast frontend powered by Vite

## 🛠️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3
- React Hooks (`useState`)
- Vite
- Git & GitHub
- Vercel

## 🧠 How It Works

Users select their preferred cake flavour, size, occasion, and custom message.

The application uses React state to track these selections and dynamically calculates an estimated cake price.

The final order details can then be passed into a WhatsApp ordering flow.
